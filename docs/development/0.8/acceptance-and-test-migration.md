## 2. 共享行为必须有共用实现的证据

**FL08-SHARED** 对应 A2.2–A2.3、A3.1–A3.2。标准包装、完全不同内部排布的独立自定义、
无默认绘制驱动均调用同一能力实现与状态转换路径；自定义不需要成为默认包装子类。

在三路分别创建隔离实例，使用相同中性输入、资格、几何和绑定模型，比较操作轨迹，而不是共享
可变实例导致三次操作相互干扰。轨迹至少记录实例／目标身份、输入归属、前后行为状态、请求及
次数、捕获／结束原因；绘制调用数另记。仅比较最终模型值会遗漏重复 Set 和错误清理。

| 案例 | 条件 → 操作 | 可观察结果 | 禁止结果 |
| --- | --- | --- | --- |
| H1 | 三路选同一激活能力，具备资格及同等几何 → 输入同一次已成立的激活，再重绘 | 三路各派发一次；重绘不再派发；headless 绘制回调调用为零 | 将透明绘制算无绘制；绘制次数控制业务；三份激活代码仅结果相同 |
| H2 | 三路同一范围能力及有效映射 → 取中点，再捕获拖出轨道后释放 | 相同目标／约束及归属轨迹；拖出不冒充丢捕获，释放后无捕获 | 自定义绕过资格；headless 自造捕获机；无操作时修复模型 |
| H3 | 缺失指针必要几何 → 请求指针操作；另给具备资格的语义操作 | 指针不伪造命中，给可定位条件缺失；语义路径按所选能力运行 | 以零 rect 命中；静默降只读；语义路径绕过禁用等适用资格 |
| H4 | 输入已消费／禁用／被覆盖，分别驱动三路 | 相应不合格操作不产生请求；已持捕获的继续与新按下分别判断 | 呈现重建第二套资格；一个输入同时派发两次 |
| H5 | 同一编辑能力显式选择相同已获准政策 → 输入草稿、读取模型、触发该政策操作 | 标准／自定义／无默认绘制复用相同草稿协调与绑定路径 | 平台字符编辑器代替业务状态机；先实现候选 Live／无效稿默认再称已验收 |

H1 的激活来源与 H2 的映射是显式测试输入；F1 已另行批准 Button 松开／Slider 即时请求的指针默认，不批准 B3 键盘增量。
H5 可先验草稿／模型分离和只读保护；依赖 B1 结束政策的部分待裁定后补，不能据此阻塞 H1–H4。

**必须同时交付两类共享证明：**

1. 运行轨迹：三路实际进入同一生产行为实现（测试侧计数／调用观察可用，不新增必需公共 API），
   不调用默认绘制也可完成状态转换；标准与自定义绘制只消费事实。
2. 依赖／调用核对：从三个入口追到同一转换与派发实现，列出生产符号及来源文件；headless 不挂
   一套 test-only 行为，自定义／适配器无复制的激活、草稿冲突或清理状态机。

## 3. 身份与结束不靠绘制顺序猜测

**FL08-IDENTITY** 对应 A3.1；**FL08-END** 对应 A3.3。

| 案例／合同 | 条件 → 操作 | 可观察结果 | 禁止结果 |
| --- | --- | --- | --- |
| I1／IDENTITY | 同一宿主 keyed A/B，各有不同稿 → 重排并兼容替换呈现 | 状态仍归 A/B；同 Bind 的两编辑器仍独立 | 用行号／视觉私有路径换身份；把包装定义状态传给派生实例 |
| I2／IDENTITY | A 有草稿，getter 改指 B 且目标作用域明确改变 → 下一输入 | A 的失效状态结束；B 不收到 A 草稿；稳定节点 key 不掩盖目标替换 | 将 A 的稿写入 B；自动推断任意跨父级迁移 |
| E1／END | 默认编辑包装有未提交稿 → 隐藏再显示同一有效节点 | 隐藏结束不适用输入、不补发失焦提交；保稿，显示时核对模型，不自动恢复捕获 | 把隐藏当删除／取消；显示时重放输入；以节点仍在证明稿仍在 |
| E2／END | 活跃节点有捕获／弹窗／订阅 → 移除或能力不兼容，再同 key 新建 | 失效引用与所属资源释放；新实例无旧输入 | 被移除节点回答后续 Cancel；同 key 自动复活销毁状态 |
| E3／END | 宿主 A/B 共享外部服务 → A 实际关闭并重复 Dispose；回调内关闭也覆盖 | A 资源释放一次，B 仍有效；模型／共享服务不被销毁；无关请求不重放 | Dispose 保存／回滚／否决关闭；关闭后执行正常帧收尾 |
| E4／END | 纯呈现抛错而身份／行为可靠；另测几何或目标不可靠 | 前者保留兼容状态，后者暂停受影响输入；错误上下文可定位 | 一律清空全部行为；异常遍历把未访问节点当删除；发布半成品命中／布局 |
| E5／END | Set 先改变模型再抛错 → 恢复安全观察 | 保留原错误及目标上下文，读回实际模型，不重试 | 假定未写入、自动回滚、将异常记正常完成 |

纯层用明确目标、资源计数器及故障注入验以上状态；适配检查原生捕获／焦点及窗口关闭落实。
可协商关闭另验宿主可拒绝，已发生实际销毁不能再否决。E1 的默认保稿已确认，不批准 B1 无效稿／失焦政策。
