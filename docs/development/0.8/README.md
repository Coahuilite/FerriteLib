## 第一部分：架构规格

### A1. 产品目的与稳定边界

**已确认。** UiKit 是通用 UI 基础设施，不限于设置页。作者表达内容、关系和业务意图，
库负责共同交互与运行复杂度，减少手算像素、重复状态机和手工收尾。
保留式、响应式与节点树是实现便捷开发的手段，不是要求作者接受更多接线工作的理由。

**core 语义是长期可依赖的基础能力与行为合同，不是所有库内共用代码的总称。**
在能力及适用前提不变时，换呈现、包装或消费方仍应成立的规则，才属于相应稳定合同。
语义包含真实操作和状态转换，不只是名称、描述或回调。

- 基础合同明确事实权威、操作含义、资格、状态转换及适用结束条件。例如草稿不同于业务值，
  请求不同于业务接受，取消未提交输入不同于回滚业务，同一次操作不重复派发。
- Live 的缺省、失焦是否提交、模型变化时保稿还是跟随，是包装政策。
  库可以共享这些政策的实现，但不因此把一种选择固化成 core 语义。
- 会话、绑定和平台有自己的协作合同；不全部命名为语义原语。
  可观察的读回与更新时序遵守 FL08-U1～U6；状态存储、队列、缓存结构和去重算法属于实现设计。
- 没有选择的能力，不强加其状态或前提：Button 不背负编辑草稿，普通文本不承担数值解析。

### A2. 职责、包装与呈现

#### A2.1 四个平行问题与九组职责

**已确认。** Structure 回答存在、身份和组成；Layout 回答尺寸与位置；Semantics 回答
能力、操作、资格及状态；Appearance 回答外观和绘制。四问不是四层调用栈。
Resolution 决定多个来源如何取舍，Ownership 决定状态与资源由谁负责。

| 编号 | 职责 | 边界 |
| --- | --- | --- |
| R1 | 结构与身份 | 节点、部件、父子及稳定项关系；不决定业务值或最终几何。 |
| R2 | 布局与几何 | 度量、分配、排列、视口与裁剪；向输入、呈现和观察提供一致几何。 |
| R3 | 行为与语义事实 | 激活、布尔、数值／范围、文本编辑、选择、滚动、展开及描述性能力；按所选合同执行。 |
| R4 | 会话与输入协调 | 输入归属、焦点、捕获、弹出／模态、状态承载和资源寿命；不包办每种行为规则。 |
| R5 | 绑定与变更通知 | 读取模型、提出请求、观察变化和释放订阅；模型保持业务权威。 |
| R6 | 样式与呈现 | 属性解析、绘制及度量需求；读取行为，不从画法重建资格或业务状态。 |
| R7 | 声明、装配与更新 | XML／程序入口、校验、派生／组合、Repeat 和文档更新。 |
| R8 | 宿主与平台适配 | 具体平台的真实输入、窗口资格、焦点／捕获／IME、线程与生命周期接入；绘制后端执行中立意图并管理具体资源。 |
| R9 | 语义投影与诊断观察 | 从真实运行事实提供 agent 读面，关联用户反馈；不维护另一棵业务权威树。 |

职责不对应固定类数或程序集数。字体影响度量、几何影响命中、焦点影响呈现是必要协作，
不以消除这些联系为低耦合目标。

#### A2.2 默认包装、派生与独立组合

**已确认。** 常见控件是替作者接好能力、身份、结构／布局、输入与呈现的包装。

| 使用路径 | 作者提供 | UiKit 提供 |
| --- | --- | --- |
| 默认包装 | 内容、绑定及支持的实例／环境配置 | 可直接使用的完整组合，不要求普通作者实现 Measure／Draw。 |
| 派生包装 | 继承默认或其他自定义包装，声明差异 | 复用行为与状态合同，差异不回写基底。 |
| 独立自定义 | 所需能力、结构、布局与呈现 | 所选能力的共同实现，不强制继承默认包装。 |

默认包装**定义**不可由消费者原位改造；正常实例配置仍可变。基于默认替换内部结构、
呈现或配方时形成派生包装。不预定 C# 继承层级，不要求每种视觉变体注册全局 kind。

整体替换呈现和内部排布不受固定私有节点树或插槽限制；需要保留的是行为必要职责：

- Button 需要明确逻辑操作目标及所选输入路径的有效区域。背景、图标和文字不各自成为按钮。
- Slider 需要有效行程、方向、可操作区域，以及数值位置与视觉位置的对应。
  滑块可不单独绘制；轨道、标签和刻度不因此成为独立行为。
- 独立操作有独立身份和输入归属，装饰不抢焦点。缺失必要合作条件须诊断，不能静默降为只读。
- 仅换外观不改交互资格；圆角绘制不自动改变命中，直线改圆弧取值涉及输入映射而不只是换皮。

#### A2.3 headless

**已确认。** 标准、自定义和无绘制路径复用同一行为；不新建 headless 状态机或事件循环。
不调用默认绘制仍可驱动和观察行为。无绘制不等于隐藏、删除或销毁。

指针路径仍需有效几何；没有几何时不伪造命中，可走满足资格的语义操作路径。
原生文本输入需要的真实焦点、几何及平台条件仍由适配满足。

### A3. 状态权威、身份与统一结束

#### A3.1 一个事实，一个权威

**已确认。** 业务值、业务错误、忙碌及保存状态属于业务模型；草稿及适用交互状态有实例和
宿主归属，由相应行为修改、会话承载；几何由布局决定。观察和缓存从这些事实派生。

包装继承不继承运行状态，同 Bind 不合并编辑实例。稳定逻辑身份且能力／业务目标仍适用时，
保留相应状态；行号、显示文本和默认视觉树路径不代替稳定 key。
同一目标改值与换目标分开；若 getter 从对象 A 转向 B，须通过稳定项键或目标作用域表达，
不能把 A 的草稿写给 B。首版不自动推断任意跨父级迁移。

**普通绑定。** Get 读取模型，Set 提出请求，通知或明确观察路径提供变化事实。
正常返回、值相同或不同均不能证明业务接受、拒绝、规范化或持久化成功。
首版不引入通用业务回执、全局操作编号、来源证明或整页事务。
需要延后应用或业务失败保留数据时，可绑定应用待编辑模型与业务状态。

#### A3.2 输入及本地组合

禁用、只读、隐藏、遮挡、模态与已消费输入分别表达。呈现或子级 enabled 不绕过适用资格；
开始操作与捕获后的继续／释放分别处理。

组合明确声明哪个本地操作参与哪个编辑过程；邻近、同容器或同 Bind 不授予清稿权限。
以下接替协调及 B3 组合默认已确认：
明确接替与普通失焦统一仲裁，不先补交旧稿再执行新操作。
仅按下、开始捕获或未成立的激活不构成接替。一次确认／步进至多产生一个写请求；
Slider 的多个真实取值样本可以分别请求。

**K1 新增键盘范围已批准延后：** 库级结构焦点顺序／遍历及聚焦控件按键映射不计首版已实现；原生编辑、IME 和现有 Accept／Cancel 不延后。
Cancel 依次处理弹窗、所持捕获、活跃编辑和最近适用的树返回动作，最后交宿主；
Accept 只交适用编辑。文本换行和 IME 合成先按文本／平台规则解释。

#### A3.3 统一结束

**已确认。** 结束原因和资源归属由 UiKit 统一处理；包装选择允许的保留政策，不复制状态机。

| 情形 | UiKit 保证 | 默认／政策边界 |
| --- | --- | --- |
| 同一节点隐藏／折叠 | 结束不适用输入，不补发失焦提交，保留仍适用数据 | 默认编辑包装保稿；派生可明确弃稿。再次显示核对模型，不重放输入或自动恢复捕获。 |
| 移除、不兼容能力或业务目标替换 | 清理失效状态、活跃引用、弹窗及待处理输入，不转交新对象 | 跨页面／销毁保留由应用待编辑模型承担。稳定 key 不保证复活已销毁状态。 |
| 可协商关闭请求 | 仍在有效目标上处理 | 宿主可提示、保存或拒绝关闭。 |
| 实际关闭／销毁 | 幂等释放自己的会话、订阅和依赖 | 不在 Dispose 中保存、回滚或重新否决关闭，不销毁外部模型／共享服务。 |
| 异常中止 | 按影响范围结束不可靠交互，不冒充正常完成、不重放操作 | 原 owner 存活且状态可靠时保留可恢复输入；新尝试须明确发生。 |

这些情形不伪装成普通失焦、确认或取消。已合法发生的普通失焦不由后续隐藏撤销或重复派发。
兼容呈现替换和重排保留适用状态；临时弹层遮挡不自行制造提交／取消。

纯呈现故障不直接清空兼容行为状态，几何／目标不可靠时暂停受影响输入。
整次处理中止不发布半成品布局或部分命中，也不把尚未遍历的节点当删除。
finally 恢复上下文和释放确定应释放的资源，不无条件执行正常帧收尾。

setter 可能先产生副作用再抛错：保留错误上下文，不推断未写入、不重试、不自动回滚；
恢复可安全观察后读取实际模型。文档恢复也不承担业务副作用回滚。

#### A3.4 自动依赖与局部更新

**已确认；响应基础、RU1 与 RU2 已接生产链。** 在现有绑定／通知／脏标记基础上引入可观察状态、自动依赖追踪、
派生计算与缓存及局部更新范围。绑定连接读值、写请求或命令；订阅取得变化事实；追踪记录
计算实际读取的可观察来源，不承诺拦截任意普通 C# 字段或集合原地修改。具体表面见 A8。
重新求值时按实际读取更新该计算的依赖；分支不再读取的旧来源，解除该计算对它的订阅。
保留实例的真实隐藏按下节 RU3 展示需求处理；不以输入失焦推断无人消费。

普通作者只表达内容、关系与业务意图，不重复罗列依赖、手写通知或缓存键。常规测量／呈现影响
由消费控件与阶段合同承担，默认包装接好；特殊扩展仍表达自身真实影响。常规对齐、排列、
尺寸适配交库处理，风格化需要可选有明确含义的偏移。

范围显式确定，数据依赖自动发现；内部可细粒度复用，按真实对外布局结果传播。范围不是
依赖墙，也不另起事件循环：父约束、字体／密度等共享环境、共享列等跨范围协作仍可使结果
失效。脏标记表示派生结果可能失效，不是历史事件清单；业务逐次事件另行处理，展示可以合并。
需要逐步可见时建立展示时间过程。RU2 A～E已确认并实现：父级使用子尺寸、Scroll使用实际内容范围、共享列使用实际贡献／组宽；缓存按阶段真实输入与合法度量环境判断，先验证子结果再决定父级复用。具体入口、旧条件与可验证边界见布局局部复用合同。

#### A3.5 更新生效合同 FL08-U1～FL08-U6

以下 ID 仅指 FL 更新合同，不与 US 同名 U 编号混用。

| 合同 ID | 已确认语义 |
| --- | --- |
| **FL08-U1** 数据可见性 | 赋值立即改变业务数据，业务主动读取可见中间值。派生可惰性求值，但依赖失效及时记录；显式读取不返回已知过期缓存。 |
| **FL08-U2** 批次 | 一次命令是隐式批次，嵌套合并到最外层结束，自动观察不插入批次中间；外部更新可从批次入口接入。批次不是事务，不自动回滚已发生业务写入。 |
| **FL08-U3** 展示同步 | 在宿主允许的呈现机会先同步展示输入，再测量／布局，最后绘制；同轮使用一致展示输入。处理中新变化到下个合法同步点，不递归重入布局。不固定为 tick、某个原生 Repaint 或必然延迟一帧；即时交互反馈不一概冻结。 |
| **FL08-U4** 执行资格 | 命中使用有效呈现几何；执行时按最新权威业务状态重新检查资格。enabled 是 UI 投影，业务入口保留拒绝权。 |
| **FL08-U5** 响应与副作用 | 逐次业务操作不被展示合并丢弃。状态驱动自动响应可在批次结束合并运行，不依赖窗口或重绘；保存不默认绑定刷新。先完成依赖失效，再让响应读取；响应写入形成后续调度，不递归调用订阅链。循环／失败须可定位；纯计算按相关输入／明确重试，消费者自动回调失败暂停至 owner 明确恢复，独立队列继续。 |
| **FL08-U6** 读阶段 | 新受追踪计算、测量与纯绘制不得修改业务状态、顺便保存或发命令。输入／命令可写，即使旧宿主在同一 Draw 栈处理输入；按职责而非方法名区分。新纯度前提不静默倒灌旧 getter／扩展入口。 |

业务读写、批次结束后的自动响应、宿主展示同步是不同阶段。展示只见最终值不表示中间值
不存在或保存成功。既有定义换版的暂存／回滚合同也不把业务批次变成事务。

#### A3.6 失败、展示需求与受管寿命（RU3 已确认）

上一份成功展示与当前有效派生读取分责；首次失败明确不可用，不伪造 0／空串／空列表。默认包装保留可靠的旧文字／控件展示并标故障；纯 paint 不重新执行输入、编辑 Observe、业务请求或资格判断。当前派生读取仍失败，依赖失败值／目标／资格／几何的操作停止；有效几何与最新资格可独立确认的工作继续。共享布局失败不发布半几何，也不把旧几何当当前命中。

纯计算失败缓存本次尝试，恢复依赖是本次实际读取（含首次／失败子级），不混入旧成功分支。仅相关可观察输入变化或明确重试允许再试；读取、绘制、计时、复显不解除。消费者显式交 FL 自动调度的可写／副作用回调失败后暂停该回调，owner 核业务结果并明确恢复后只处理当前状态；独立队列／服务继续，已发生写入不回滚、不补偿、不重放。普通按钮下一次点击是新的明确请求。

保留实例且明确隐藏时推迟已知无人消费的纯展示求值／测排；可见显示、布局或明确消费者仍使用的共享计算继续。复显采用最新安全输入并完成有效几何后接受输入，保同目标可靠草稿，不自动提交、补演刷新或恢复 R1／R2 故障。旧 custom 未提供完整需求时保原合法条件及保守服务，不暗加必需接口或纯度前提。

失焦、隐藏、遮挡、模态、销毁分别表达。各 Host 只释放自己的会话；共有计算由实际共享 owner 持有，不因 B 失焦／关闭停止 A 或外部业务。B 所属非阻止确认保原目标 A17，不随选择 B23 重定向，执行由业务再次核当前资格；实际销毁清 UI 待确认状态，不代确认或撤销业务。不承诺现有后端全部模态形态或通用遮挡分析。

明确纯求值回路与重复推进预算耗尽分开诊断并结束 FL 自身推进；按真实身份／依赖／调度边界报告停止范围和 R1／R2 恢复入口，不因下次绘制续跑。有限反馈应完成，大量独立一次更新不误判；预算不是完整回路证明，不承诺中断不返回回调或猜业务最终值。实现参数与证据只在[失败与寿命合同](failure-lifetime-contract.md)维护。

### A4. 布局与属性

#### A4.1 几何决定权与首版布局

**已确认。** 作者声明关系；内部报告尺寸需求；父级分配外框；内部布局安排部件。
自然需求不授予控件自行扩大外框的权力。宽度影响高度时，按实际分配宽度度量。
外层 Row 不需要理解 Slider 私有部件：标签移到上方后，包装报告包含标签换行的需求，
而不是要求作者补几个 px。

自动与自由布局可嵌套，同一几何自由度不能有竞争写入者。影响占位的调整、整体呈现移动、内部装饰偏移须分别有确定布局／坐标含义；不批准通用变换系统，也不改变自由定位占位规则。位置／偏移属于所选布局的输入，
不靠最后赋值者获胜；绘制、命中和观察共用有效几何及裁剪。

首版保留现有行／列、Wrap、叠放、容器、视口、自然／显式尺寸、Min／Max、Fill、间距及
容器级响应式用途，并补齐：

- **有限关系定位：** 父边缘／中心，以及同一自由定位容器直属子对象的边缘／中心依附。
  不跨宿主、任意跨树或跨 Repeat 项引用；循环、失效引用和竞争几何有可定位诊断。
- **共享标签列：** 同组按有效内容度量共同列宽，形成标签／字段对齐，不引入通用二维网格。
- 包装内部参与测量和排列；字体、内容、密度和区域变化触发适用重算。

其余新增高级布局延后：完整 CSS Grid、任意约束求解、通用变换命中、全页面断点系统和
新增文本基线对齐均不列首版必交；不削减已有容器级响应式。

**L1 已确认：** 内容默认自然增长，显式固定尺寸受其约束；不足时提供定位诊断，
不静默压破声明 Min／Max、不自动加滚动／裁剪或省略。既有显式滚动／裁剪及适用包装换行保持；1px 几何保底不是可用性最小尺寸。
刻意覆盖不自动挤走兄弟；自由定位内容对自然尺寸的贡献须由其布局说明。
滚动位置只有一个权威，布局提供范围而不另外保存一份位置。

#### A4.2 属性来源、继承与 override

**已确认。** 对已声明可继承的环境属性，逐属性采用以下优先级：

1. 实例显式声明。
2. 作者明确应用的局部样式／派生包装中的显式样式。
3. 最近的可继承环境声明，包括祖先明确选择的适用样式。
4. 宿主／主题适用缺省。
5. 包装／库保底。

未声明、显式声明和当前有效值分开。默认不升级为作者覆盖，父级兜底取得的整包结果不变成
显式声明；命名样式缺项继续寻找来源。显式值即便等于缺省，也保留覆盖意图。

撤销 override 只移除对应声明，按当前剩余来源重新解析；不恢复创建快照、不重置无关属性、
不复制父值后固定。父级从 Small／常规改成 Medium／紧凑，Slider 的显式 Tiny 保持；
撤销字体 override 后得到 Medium／紧凑，并继续跟随。存在另一局部字体样式时，先由该样式接替。

字体与密度独立；密度不自动等于字体缩放。父容器 Padding 不要求子级复制同值。
业务值、绑定、角色、草稿、捕获、最终几何和编辑政策不作为环境属性一概继承。
度量输入变化重算布局，纯换色更新呈现；来源变化即使值不变，也更新以后的跟随关系。
样式变化不成为提交、取消或销毁。

**P1 已确认：** 现有字体、语义颜色和 Padding／Spacing／Gap／RowHeight／Hairline 五项度量开放。
每层一个 Scheme、一个 Density；Density 逐项盖 Scheme，实例显式最高，稀疏项继续找当前来源。
`Metric.*` 与逐项运行声明／撤销配置内部度量；裸容器 Padding／Gap 仍仅控制自身分配。
默认私有结构和默认外观保持，不引入任意样式列表、全属性继承或 CSS 选择器。

## 第二部分：默认包装合同

### B1. 共同编辑

**E1–E5 全部确认。** 默认 Live=false、无效／冲突保稿、取消只动草稿；确认正常返回结束稿并显示实际模型，普通有效无冲突 blur 提交。当前消费者 US 后续迁移须显式 Live=true，现未消费本 Dev。NumberField、单行和基础多行共用编辑能力及协调实现；
包装选择政策，不各自维护 dirty／冲突状态机。实时发布到绑定目标，与业务应用／持久化分开。
Live=false 不是整页事务，也不延后 Slider 直接选值或 Button 明确操作。

| 事项 | 推荐默认 |
| --- | --- |
| Live | 默认 false，编辑先留草稿；显式 true 时新的合格候选可实时发布，不结束编辑或打断输入串／光标。 |
| 确认 | 按当前资格和约束检查，有待发布的有效修改则请求一次；正常返回后结束草稿，显示模型。无实际修改，或候选已由 Live 发布且无后续候选／已知依据变化，不重复写入。 |
| 普通失焦 | 无效或有已知依据变化的稿保留并反馈，允许焦点离开；其余有效待发布修改走确认路径，无待处理修改则结束编辑。 |
| 无效稿 | 保留原串和原因，不发布，不自动转为 0／空值或静默恢复模型。普通文本空串本身合法，有效性由适用解析／约束或显式本地校验决定。 |
| 模型变化 | 未实际编辑则随动；已有编辑稿则保稿并提示变化，暂停 Live 与失焦的自动发布。显式确认可采用自己的有效稿，不默认二次确认；取消采用最新模型。 |
| 取消 | 丢未提交输入，显示最新模型，不回写编辑开始值，不撤销已发布的 Live 内容。 |

无效稿与业务未采纳不同。正常提交后模型仍为旧值或其他值，也结束稿并显示模型，不猜原因、
不恢复重试；Live 请求不结束编辑，保留串直到按所选规则结束。抛错按 A3 异常处理。
需要业务失败时保留完整输入与错误信息，可绑定应用待编辑模型；不增建通用回执。

普通失焦不包括 A3 的隐藏／销毁／异常或明确本地接替。保留稿在实例有效时继续存在并显示未完成状态。
模型观察与本地派发须协调，通知不制造写入，不为追平草稿与模型循环 Set；具体算法不在本规格固定。
没有被观察到的变化不承诺检测，不提供原子并发控制。

作者可启用 Live；派生／自定义包装可选择失焦提交／保留／放弃、无效稿保留／明确放弃、
模型变化保稿／明确跟随，以及显式覆盖前额外确认。丢稿含义须明确，不冒充成功提交。
这些是政策接缝，不要求首版公开所有组合开关；只读、IME 保护和生命周期等适用合同不能绕过。

### B3. 数值、Slider 与组合

数值能力依据显式基数／目标和声明范围、步进形成请求，不自行发现别的控件草稿。
非有限或不能解析成适用数值类型的请求不写；范围上下界顺序有效，越界候选按声明约束处理。
显示格式不改变业务值；模型超出声明范围时显示差异，不擅自回写修复。

**已确认的依赖边界：** Slider 按几何选择目标，不依赖 NumberField 草稿。
连续 Slider 不因旁边有 Step 按钮就隐式离散化。NumberField 组合编辑与数值解析，沿 B1 处理编辑默认；
临时 `-` 不自动变成 0，仅聚焦或显示舍入不制造写入。

**F1 已确认：** Slider 真实选值即时提出请求，不等释放、不依赖 NumberField 草稿；重绘不重发，捕获拖出／释放按归属处理。
**K1 新增键盘默认已批准延后：** 键盘用声明增量，无声明时建议范围跨度的 1%，
Home／End 取端点，零跨度不产生无效步进。

**N1–N3 全部确认：** 业务 10、有效已修改草稿 20、Live=false、Step=1，按+立即只请求21并结束稿；Slider 明确30只请求30，不先20。明确参与本组合的捕获先于普通 blur，但仅捕获不清稿。

- 组合增减沿有效草稿直接请求 21／19，立即发布并结束旧稿；无草稿时取当前业务值，不先提交 20。
- Slider 明确选择 30 时直接请求 30 并接替旧稿；无需解析旧稿，仅捕获不接替。
- 非法稿不能提供沿稿基数，因此该步进不执行；Slider 明确选值或取消仍可接替／放弃。
  选择业务基数的另一种组合可从 10 请求 11／9，并明确如何接替旧稿。

普通独立 Button 没有清稿权限。同 Bind 的另一个编辑器也不随本组合结束。
未声明为本地接替的点击所产生的普通失焦和业务动作，按明确输入顺序处理，不靠 Draw 顺序猜测。
请求后显示实际模型；无草稿的下一次步进从模型出发，不继续沿不存在的请求值累加。
